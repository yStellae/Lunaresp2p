# Lunares — instaladores e atualizações

Este é o canal público de distribuição do **Lunares**, anteriormente chamado Discórdia. O mesmo repositório foi renomeado de `yStellae/discordiap2p` para [`yStellae/Lunaresp2p`](https://github.com/yStellae/Lunaresp2p). As versões e seus anexos foram preservados.

- [Instaladores publicados](https://github.com/yStellae/Lunaresp2p/releases)
- [Código-fonte e documentação](https://github.com/yStellae/Lunares)

## Aviso sobre o atualizador após a renomeação

As cópias publicadas até a **2.74.22** conferem o endereço antigo do repositório. Elas recusam o redirecionamento para o novo nome, por isso a atualização automática desse canal fica interrompida nessas cópias.

A correção do endereço foi integrada no código-fonte em [dbf6a7f3](https://github.com/yStellae/Lunares/commit/dbf6a7f32ca8228453888bf98282d3e401027124). Ela só chegará ao aplicativo instalado em uma **nova versão assinada e publicada**. Quando essa versão estiver disponível, baixe seu instalador nesta página e use o fluxo de atualização, preservando os perfis e conversas. **Reinstalar a 2.74.22 não corrige o endereço do atualizador.** Este aviso não anuncia uma nova versão disponível.

A versão **2.74.22** existente, publicada em 02/10/2026, continua em [sua Release](https://github.com/yStellae/Lunaresp2p/releases/tag/v2.74.22). Em 03/10/2026 foram conferidos publicamente a assinatura do manifesto, a rotação da chave e todos os bytes do instalador:

- Arquivo: `Discordia-Setup-2.74.22.exe`
- Tamanho: `137547525` bytes
- SHA-256: `23d453b77dbc2f8831bc9394c3c27f312fee298fe38a448758f0e097dfc9e977`

Essa conferência não aprova outro candidato nem altera o instalador publicado. A assinatura do manifesto é Ed25519; não é uma assinatura Authenticode do executável.

## Publicação e endereços

Novas publicações usam este repositório e continuam exigindo assinatura pessoal e confirmação do candidato exato. Candidatos preparados com o nome anterior devem ser preservados; prepare outro para conferir e aprovar o novo destino, sem editar silenciosamente um candidato assinado.

O GitHub mantém redirecionamentos do nome antigo. Não recrie outro repositório com o nome `discordiap2p`: isso pode eliminar esses redirecionamentos. [Documentação do GitHub sobre renomeação](https://docs.github.com/en/repositories/creating-and-managing-repositories/renaming-a-repository).
